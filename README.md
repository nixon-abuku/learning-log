# Learning Log

## May 6, 2026


### What I learned today

- git is a local version tracker. Github is the cloud backup.
- git init creates a hidden .git tracker inside a folder
- git add stages files for the next commit
- git commit takes a permanent snapshot of staged files 
- git push sends local comits to github

## Comands I used 
- git init 
- git add
- git commit -m "message"
- git status 
- git log
- m
